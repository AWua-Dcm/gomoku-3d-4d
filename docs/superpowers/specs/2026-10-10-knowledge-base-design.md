## 一、目标

给这个仓库建一份 **Obsidian 工程知识库**（工程外脑），服务两个读者：

1. **用户本人**——用 Obsidian 浏览、搜索、看图谱，把散落的知识翻得动；
2. **未来的 Claude 会话**——动手前先读知识库首页，快速拿到"为什么"。

解决的问题：项目的知识现在散在四处——现有文档（README / RULES_SPEC / 打开流程 / 工程 README / spec）、git 历史、Claude 跨会话记忆（仓库外、机器本地）、以及"哪儿都没写"的讨论过程。知识库把这些收拢成**互相链接的笔记**；与现有文档的关系是**索引与链接，不是复制**（这个项目本来就反对同一内容存两份，"中文只有一份"是同一个原则）。

已确认的口径（问答纪要）：

- 用途＝工程外脑，不是对外读物；
- 第一版**一次做齐**五类内容，只链接不抄写；
- 库的位置＝**仓库根目录本身就是 vault**，新笔记集中放 `知识库/`；内容随公开仓库公开（用户确认）；
- 维护＝根 `CLAUDE.md` 约定 + 链接完整性检查脚本。

## 二、库的位置与形态

- **vault 根 = 仓库根**。现有全部 `.md` 自动入库、可被 `[[链接]]` 指到——这是"只链接不抄写"能成立的前提（Obsidian 的链接只在库内作用域解析，库外文件链不到）。
- 新笔记集中放根下 `知识库/`。
- `.gitignore` 增加一行 `.obsidian/`（Obsidian 会往 vault 根写配置目录；与现有 `.vscode/` 同理：工具配置不进库）。
- 点开头目录（`.git`、`.claude` 等）Obsidian 默认不显示也不索引（验收时看一眼；真可见再议，代价很小）。`_verify/`、`docs/` 照常可见。
- 只用 Obsidian 核心功能（文件夹 + wikilink + 锚点），**不依赖任何插件**；换台机器 clone 下来、任意版本 Obsidian 打开即可用。

## 三、笔记规范

### 模板

每条半屏到一屏，结论先行，出处报到提交号 / 章节锚点。

**决策类**＝结论 / 为什么 / 代价与边界 / 证据。例：

> # 默认中文，不猜语言
> **结论**：不读 `navigator.language` 自动检测，默认中文。
> **为什么**：要的是"切换"，不是"猜"——猜错了比不猜更烦。
> **代价**：浏览器语言是英文的人第一次打开也看到中文，得自己点一下。
> **证据**：[[README]] §六种语言。

**坑类**＝症状 / 原因 / 规矩 / 出处。例：

> # python 改文件会把 LF 换成 CRLF
> **症状**：整份文件在 git 里算"全改"；或者报一个看起来毫无关系的错——「找不到 `#rulesSrc` 的 script 块」。
> **原因**：Windows 上 python 默认文本模式写文件，`\n` 全变 `\r\n`。
> **规矩**：凡是用 python 改仓库文件，读写都写 `newline=''`；改完先数一遍文件里的 `\r\n` 个数，不是 0 就是中招。
> **出处**：v3.1.7 前后的注入脚本会话（2026-10）。

（示例只是形状；真正的提交号、章节锚点建库时逐条查实。）

### 命名与链接

- 文件名用中文短语，决策类陈述式、坑类症状式；避开 Obsidian 禁止字符 `[ ] # ^ | : / \`；笔记 H1 与文件名一致。
- 链接首选 `[[文件名]]`；重名（根 `README.md` 与 `Web_Gomoku3D/README.md`）用路径式 + 别名：`[[Web_Gomoku3D/README|工程细节 README]]`。
- 章节锚点 `[[RULES_SPEC#长连负]]` 按标题文本精确匹配。
- 代码 / 脚本文件（`index.html`、`run-all.sh`）可以链，但不指望点开行为——验收时抽查一个；点不开的就改路径文本。

## 五、初稿清单（建库时按素材盘点增删）

### 决策/（14 条）

1. 单文件零依赖（内核段三处复用；线上跑的就是仓库里这份）
2. 先手恰好五连（长连负；为什么立体棋盘需要这条）
3. 四维必须立方（不是"没做"）
4. 转动两步走（预览 → 确定 / 取消；`T` 在预览期不做确定）
5. 转动按威胁触发（brk / build 跨档 + 转完不许留活三以上）
6. 视角操作：跟手指走、不做惯性、极角夹取（调研结论）
7. 默认中文、不猜语言；语言切换器用列表（调研结论）
8. 中文原文留在 HTML（外语进表；内核自带 `CORE_TEXT` 的真实代价）
9. 规则全文是生成的（`embed-rules.mjs`；起始界面为什么不再提 RULES_SPEC）
10. 单文件里塞书法字体（OFL 子集化 + base64；商业字体不能嵌；Canvas 不用子集）
11. AI 评估函数按方向数威胁（含：深度 2 刻意跳过、算杀排除长连、分支宽度越小越强）
12. 贯通看得见（影子圈；判定＝周期空间）
13. 仓库不收工具链内容（skill 清单不入库的决策）
14. 古风视觉的规矩（不抄素材、浅底赛博＝通电黛青、发光只有一处；调研结论）

### 坑/（12 条）

1. 冻结向量不能改（改＝篡改证据）
2. 路径里的空格会静默失败
3. python 改文件会 CRLF 化
4. `ev()` 里别写反引号（症状是 `JSON.parse(undefined)`）
5. fixed 只写 `top:50%` 会截高度（竖排断句；用 `getClientRects` 数）
6. 宋体会把西里尔画成全角（装饰类要按语言给字体栈）
7. 起始界面高度预算极紧（法语是边界；加一行从哪还；别动 `gap`）
8. 截图对拍先钉住会动的东西（toast / 演示盘；先量噪声底；强差异追、弱差异不追）
9. shots 基线图的真假判定（HEAD 副本对拍、结论随环境变、端口 9401 自检）
10. 自对局量棋力必须配对（对照组必须 50.0%；搜索深度用奇数）
11. 推送 GitHub 与 Pages 验证（代理、`-c` 的位置、Pages 没更新时的查序）
12. curl 抓大文件看退出码（代理静默截断，伪装成"线上被改"）

## 八、链接检查 `_verify/kb-links.mjs`

零依赖 node ESM；扫 `知识库/**/*.md`：

1. **提取**：wikilink（`[[…]]`、`![[…]]`、含 `|别名`、`#锚点`）与 markdown 链接（相对路径）；围栏代码块与行内代码里的不算。
2. **解析**：路径式精确匹配；裸名在全库找同名 `.md`——0 命中报"悬空"、≥2 命中报"歧义"（要求改写路径式）、1 命中通过。
3. **锚点**：`#标题` 在目标文件里找标题文本**精确一致**者；不支持的 `^块引用` 出现即报。
4. **外链**：http(s) / mailto 跳过；相对路径目标不存在即报。
5. **孤儿**：除 `首页.md` 外，`知识库/` 里每个 `.md` 必须至少被一条链接指向。
6. **输出**：`文件 N / 链接 M / 悬空 X / 歧义 Y / 孤儿 Z`；任何非零即 exit 1。

**自证会红**（沿用注入验证传统）：建好后故意改坏一条链接跑一次、看到红、还原——检查必须能失败才算检查。

不进 `run-all.sh`（不动游戏"九步"的叙事）；将来想挂进去是 trivial 的事，再说。
