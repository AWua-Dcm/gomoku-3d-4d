# 假测试的两起案例

绿 ≠ 有效。这里记两起"测试全绿但什么都没证明"的真实案例，写作新断言时先对照。

**案例一：只测了一半路径（v3.1.4）。** 相位光圈的断言第一版只测了二维那一遍——把三维的代码单独关掉，测试照样绿。等于断言自己在说"我只认识一半的世界"。已补第二条（三维数实例），一条测二维数像素、一条测三维数实例，两条一起才算数。

**案例二：先摆好状态再断言，正好绕过 bug（v2.10.8）。** 拉条禁用 / 「谁先下」禁用的断言，是先 `Game.setSetupAi(...)` 摆好状态再断言的——查的是"设过的状态"，而真 bug 是"页面刚打开、一个字都还没设过时，两样都是活的"。断言写得越像测试，越容易绕过现实。修法：新断言必须**在页面刚加载完、什么都没设过的时刻**跑。

**一句话教训**：每条断言写出来之前先问两句——"它能不能被绕过？""它覆盖的是全路径还是恰好一半？"
