# 证据的分级

**结论**：这个工程把结论分三档，写作时用措辞区分——✅「已由真实执行验证」/ ❌「我无法验证」/ 没有标记的就是"只是我认为对"。

**三档长什么样**：

- **✅ 已由真实执行验证**：测试真的跑过、截图真的对拍过、数字真的量过——每个数字都能指到执行记录。
- **❌ 我无法验证**：明确列出来，不装懂。[[Web_Gomoku3D/README|工程细节 README]] 的「验证状态」节分两栏列这个。
- **需要人确认的**：[[打开流程]] 专列「还没验证过的部分（需要你确认）」——配色观感、交互手感、四维转动可读性、比 900×700 更窄的窗口、英文文案地不地道、术语一致性、**棋力手感**（"弱档是不是真的能被新手赢、中档是不是还有点意思"只能人下几盘）。

**另一件关键的"证据身份"**：冻结向量是**冻结的历史基线**（与已删除的 C# 实现逐手一致），不是和某个活对照物的对拍——所以它不能"修"，见 [[坑/冻结向量不能改]]。

**出处**：[[Web_Gomoku3D/README|工程细节 README]]「验证状态」节；[[打开流程]] 的"需要你确认"表。
