# 报告过没修的清单

**结论**：一批"报告过、按当时的范围**没修**"的东西。它们大多是用户的明确决定（不是遗漏）——**再动之前先问**，别自作主张。

- **三维视图和单层棋盘的 x 轴方向相反**：yaw 归零时三维视图里屏幕中心 x=7、往右是 x=4；而 2D 面板靠左 x=3、靠右 x=11。RULES_SPEC 写的是"x 向右递增"——和面板一致、和三维视图相反。
- **状态行在手机上折成两行**：中文基线就这样，browser-check 钉的是"不超过两行"。
- **法语横屏手机模式条折三行**（占三维视图面积 27%）。
- **单层棋盘在电脑上没有缩放 / 平移**（只有触屏够得到）。
