# 拓扑玩法的两档

**现状**：贯通的判定（周期空间 / 环面）早就对、也早就有影子圈让它看得见（v3.1.0，见 [[决策/贯通看得见]]）——但 `wrapEdges` **只被教学第二关写死打开**，正常对局根本玩不到。

**欠的两档**（用户明确留着，不是忘了）：

1. **拓扑做成可选玩法**——设置页能选，电脑对手也认得它；
2. **照参考游戏做整条 7 关拓扑旅程**——平面 → 圆柱 → 环面 → 莫比乌斯 → 克莱因 → 射影 → 球面，每关一种曲面，含"引着走"的引导（参考实现是 bilibilitoy 的「拓扑五子棋」，核心数据在它的 `assets/level-config.js`：每关两条边各给一个连接方式 `xConnection / yConnection ∈ {null, same, twist, adjacent}`，还带 `edgeText` 和 `lessonPath` 五句提示）。

**再提起时先问是**哪一档——第 1 档是设置项 + AI 支持，第 2 档是一条完整的关卡内容线，工作量差一个量级。别自作主张扩范围。

**出处**：2026-09-29 的拓扑调研记录；`1d0ba0c`（v3.1.0 影子圈、拓扑可视化的最保守那档）。
