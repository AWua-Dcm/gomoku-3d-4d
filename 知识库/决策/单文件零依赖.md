# 单文件零依赖

**结论**：整个游戏就是 `Web_Gomoku3D/index.html` 一个文件——零依赖、零构建、双击即玩；GitHub Pages 上跑的就是仓库里这一份原件，没有"线上版"和"本地版"之分。

**为什么**：file:// 直接打开就能玩，不联网、不发任何网络请求。index.html 里 `/* GOMOKU-CORE-BEGIN */` 到 `/* GOMOKU-CORE-END */` 夹着的那段是**纯规则内核**——不引用任何 DOM / WebGL / 浏览器 API，所以同一份源码可以在三个地方跑：浏览器里（正常玩）、Node 里（测试用 `new Function` 抽出来回放向量）、将来做联机时当裁判的服务器。**只有一份实现**，不存在"网页版改了、服务器忘了改"这种分叉。

**代价与边界**：`index.html` 现在一万四千多行（约 90 万字节），改一次动全身。字体这类"通常放文件"的资源要子集化内联（见 [[决策/单文件里塞书法字体]]）；规则全文、颜色这类容易"两边各写一份"的东西都有单一来源约束（生成器生成 / 单一变量），见 [[决策/规则全文是生成的]]。
