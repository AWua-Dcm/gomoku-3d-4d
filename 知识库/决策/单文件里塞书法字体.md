# 单文件里塞书法字体

**结论**：主标题的行书字体是**子集化后 base64 内联**的——OFL 授权的毛笔字体（Ma Shan Zheng 一类）用 `pyftsubset` 切到只用到的那十几个字，14–16 字约 6.5KB，塞进 index.html。

**为什么**：单文件 + file:// + 不发任何网络请求是前提——不能引 CDN 字体；整支 CJK 字体是 5MB 级，Google Fonts 的 unicode-range 分片即便只取用得着的几片也要几百 KB。

**代价与边界**：**改标题 / 水印文案必须重新切子集**——不在子集里的字会渲染成豆腐块，**而且不会报错**（v3.1.7 修注释时就差点让「魔方」静默回退到楷体）；商业字体（如华文行楷）本机装着也只能当 CSS 兜底，不能嵌进仓库；**Canvas 里不要用子集字体画字**（子集外的字会回退成另一种风格，一片里混两种笔迹），子集只给 DOM 文本用。

**证据**：`7c842c1`（v3.1.6 内联书法字体）、`00663be`（v3.1.7 重切并把 pyftsubset 命令补全）。
