# 视角操作不做惯性

**结论**：手势分配照主流——单指旋转、双指缩放 / 平移（与 three.js OrbitControls 的 `ONE: ROTATE / TWO: DOLLY_PAN` 同款）；方向一律"内容跟着手指走"；上下拖到底停在 ±89.5°；**松手完全静止**——不做惯性是刻意的（选点精度优先）；双击＝复位。

**为什么**：不做惯性有先例——OrbitControls 的阻尼（`enableDamping`）默认就是 false；±89.5° 的极角夹取与 Babylon 默认（0.01 rad ≈ 0.57°）同量级。调研过：这是主流取值，不是偷懒。

**代价与边界**："双击复位"不是 3D 查看器的主流（主流的双击＝聚焦到该点，复位走显式入口）——我们保留它，且复位是**按当前 aspect 重新取景**，不是回到写死的相机位；点击 vs 拖拽的阈值（约 50px）是应用层自己定的（平台基准约 8–10pt）。

**证据**：2026-09-26 的手势调研记录（对照过 OrbitControls / Babylon / model-viewer 源码）；[[README]] 操作表。
