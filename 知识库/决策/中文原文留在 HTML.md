# 中文原文留在 HTML

**结论**：中文文案留在 index.html 的 HTML 里，外语进字符串表；切回中文＝把 HTML 里那份原文写回去。

**为什么**：中文只有一份——不会出现"HTML 一份、表里一份"各自漂移。

**代价与边界**：真实代价不是可以绕开的细节——规则**内核**里也有六种语言的文案（内核本来就在拼中文句子：黑 / 白 / 状态描述），而它必须能被 server.js 和三个测试**原样抽出去跑**、叫不到界面文案表，所以自带一张 `CORE_TEXT` 表；不传 `lang` 时逐字节等于从前，联机协议因此仍是中文。单复数按语言选形：中日韩没有复数、英法两形（法语把 0 算单数）、俄语三形（1 / 2–4 / 5+，且 11–19 归第三形）。规则只有一份，住在内核里——界面也要用，而内核叫不到界面。

**证据**：[[Web_Gomoku3D/README|工程细节 README]]「界面语言：中文 / 英文」各节（含「内核里也有英文——这是个真实的代价，不是一个可以绕开的细节」）。
