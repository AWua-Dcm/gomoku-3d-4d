# 默认中文不猜语言

**结论**：网页默认中文——**不读 `navigator.language` 自动检测**；右上角语言键点开是六种语言的**列表**（各语言的本族名、当前那种高亮），选择记进 localStorage。

**为什么**：要的是"切换"，不是"猜"——猜错了比不猜更烦。调研结论：语言多于两种时没有一个主流实现用循环按钮，全是列表；按钮显示当前语言的本族名，不用字母代码、不用国旗。

**代价与边界**：零依赖单文件，不引 i18n 库——`data-i18n` 属性 + 内联表就是这类站点的主流做法；**不 fetch JSON**（file:// 下会被 CORS 挡掉）；file:// 下 localStorage 抛 `SecurityError` 要有安静降级。

**证据**：[[README]]「六种语言」节；调研对照过的两个已读实现——[hermes-agent 的 LanguageSwitcher](https://github.com/NousResearch/hermes-agent/blob/main/web/src/components/LanguageSwitcher.tsx)（从双态 toggle 改成下拉，因为语言涨到 16 种）、[OpenMAIC 的 language-switcher](https://github.com/THU-MAIC/OpenMAIC/blob/main/components/language-switcher.tsx)（portal 到 body，因为父容器 overflow 会裁剪）。
