# 古风视觉的规矩

**结论**：将来再做视觉先读这篇——五条可复用的规矩：①只借**方法论**、不搬画面：纹样按几何规则自己画，不扒素材站 SVG（免费≠可商用；博物馆的高清数字化文件有特别经营权）；②浅底上做赛博＝把**已有的黛青"通电"**（色相微移 + 饱和度拉起），不加新色相；③全页只有**一处**发光、面积 <2%、只动 alpha 不动色相；④浅色主题里霓虹**发不出光**（原生霓虹青在纸白上对比度约 1.45:1）——这个"缺陷"本身就是克制，别去修；⑤别用大阵列 `radial-gradient` 铺点阵（有实测卡顿案例），要铺就换 SVG data-URI 平铺。

**为什么**：这套东西是这个仓库"古风 + 一点点赛博"视觉方向的思考结晶——公版纹样清单、对比度实测、性能反例都量过一遍，不记下来下次还会重新踩。

**代价与边界**（实测数字与三轮废稿）：纸底 `#efe8db` 上的对比度——朱砂 5.87、黛青 5.79、赭石金 3.80（只够大字）。废稿教训：往白线框立方体背后铺网格 / 裂纹＝线条叠线条，糊；横穿画面中部的装饰带会压过正文和「开始游戏」；暖米底上低透明度的青会变成**灰绿脏点**；48px 的回纹角花在屏幕上读起来是**四个污点**不是纹样。

**证据**：2026-09-28 的视觉调研记录；`6299ed2`（v2.10.13 重打光 + 印章通电）；`7c842c1`（v3.1.6 古风重构）。
