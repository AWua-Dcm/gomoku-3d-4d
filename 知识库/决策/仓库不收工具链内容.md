# 仓库不收工具链内容

**结论**：Claude Code 的 skill 清单 / 官方插件市场的内容**不进这个仓库**，也不写进 README。已经决定：什么都不做。

**为什么**：先说许可——那些 skill 出自 Anthropic 官方插件市场，拷进一个 MIT 仓库就不是干净的许可了。再说不值：副本会随插件升级越走越远，最后成一份长得像真文档的假文档；而这个仓库的读者是来玩棋、来读单文件实现的，对他们零价值，还和「单文件零依赖」的立场打架。何况 skill 本来就住在本机用户目录里——它跟机器走、不跟仓库走，别人克隆也拿不到。

**代价与边界**：值得写进仓库的是**项目规约**（改完跑什么、什么不许改）——那是 [[CLAUDE.md]] 的活；工具链内容留在本机。

**证据**：2026-09-28 的决定（当时会话记录）；[[CLAUDE.md]]。
