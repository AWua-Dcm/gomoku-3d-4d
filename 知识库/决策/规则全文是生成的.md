# 规则全文是生成的

**结论**：页面上「具体规则」浮层显示的六份规则全文，是 `_verify/embed-rules.mjs` 把六份 `RULES_SPEC*.md` 嵌进 index.html 生成的——**要改规则，改 md、重跑生成器、提交生成结果**。

**为什么**：手写两份必然漂移。页面里那份和仓库里的文本文档保持一致是"构建出来的"，不靠人盯。

**代价与边界**：改了 md 忘了重嵌＝页面还显示旧规则（有测试盯着：dom-smoke 从生成的 script 块里抽正文来验）；起始界面因此**不再提「RULES_SPEC.md」这个文件名**——玩家不需要知道文件名，只需要点「具体规则」。

**证据**：[[Web_Gomoku3D/README|工程细节 README]]「规则全文：为什么它是生成的」与「起始界面上为什么不再提 RULES_SPEC.md」两节。
