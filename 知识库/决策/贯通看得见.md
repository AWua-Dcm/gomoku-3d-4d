# 贯通看得见

**结论**：贯通的判定＝把棋盘展开成**周期空间**——27 副棋盘叠起来、只下中间那副，每手印到其余 26 副；换句话说就是把棋盘卷成一个环面。v3.1.0 起用**影子圈**把它变得看得见：棋盘外紧贴一圈，画出边界棋子的"续集"。

**为什么**：判定本身早就和参考实现（拓扑五子棋）等价——缺的一直是"让玩家看得见"；贴边的子在对侧长什么样，不该让玩家脑补。

**代价与边界**：现在 `wrapEdges` 只被教学第二关**写死打开**，正常对局根本玩不到可选拓扑；参考游戏把拓扑做成 7 关旅程（平面 / 圆柱 / 环面 / 莫比乌斯 / 克莱因 / 射影 / 球面），我们只做了最保守的"影子"这一档（见 [[待办/拓扑玩法的两档]]）。

**证据**：`61a9f2b`（v3.0.0 贯通规则层）、`1d0ba0c`（v3.1.0 拓扑可视化）；[[RULES_SPEC#10.4 空间贯通：六个面打通]]。
