# AI 评估按方向数威胁

**结论**：叶子评估按**方向数威胁**（wins / fours / openFours / threes / twos / over）+ 量纲对齐，取代旧的 `max(各方向棋型分)`——那个是几乎没梯度的分段常数。

**为什么**：换评估实测是 +131 elo 量级（同类 JS 引擎口径），而单纯调权重是 0 到 −70。三个收益：滑窗天然认得跳形（旧的 aiGappedBonus 删除——留着会重复计分）；双四 / 四三 / 双活三有了专门档位（13 方向立体盘上比平面常见得多）；长连对受限方是负分。

**代价与边界**（一串"量过、没留下"的数，别再试一遍）：极限档深度 5→7 → 33.3%（更弱）；转动交给同一段搜索估值 → 31.3%（更弱）——**瓶颈是叶子评估太粗，不是算得不够多**；算杀进叶子 → 50.0% 且耗时翻倍；低档三条变强路 → 46.7 / 40.8 / 47.5%；深 6 要 577ms 且只强 60%（极高档因此从深 6 改深 4）。另有两条铁律：**深度一律奇数**（深 2 打深 1 只有 29.2%）；**分支宽度越小越强**（支 4 打支 8 拿 22.5%——要变强加深度或加算杀，别加宽度）。候选排序必须用加号（我攻＋对方守），叶子评估里对方项要打折（`AI_EVAL_W = 0.5`）。

**证据**：index.html 里 `AI_PARAMS` 上方"量过、没留下"的注释；`4337e18`（v2.10.14）；[[历史/AI 棋力提升史]]。
