# fixed 只写 top50 会截高度

**症状**：竖排文字断句怪怪的、版面被横向拉长（实测外框从 422×690 变成 782×401）——静态看截图只能看出"有点不对"，看不出根因。

**原因**：`position: fixed; top: 50%; transform: translateY(-50%)` 这个"垂直居中"的写法，**没写 `bottom` 时包含块是"top:50% 到视口底"那一段**——可用高度只剩视口的一半。单行横排看不出来；`writing-mode: vertical-rl` 下 height 决定"一列放得下几个字"，1600×900 下可用高度只有 401px，只放得下 3 个字，于是 4/6/5 三句被强行折成 6 列。

**规矩**：竖排元素要**显式给足高度**——写 `top: 7vh; bottom: 7vh`（居中靠上下等边距，不靠 transform）。排查断句一律用 `Range.getClientRects()`：**一列 = 一个 line box = 一个矩形**，三句话就该是三个矩形（滤掉 `height <= 1` 的零高占位矩形）。这条已钉进 `_verify/browser-check.mjs`：断言"正好 3 列" + "外框高 > 宽"。

**出处**：`3ab96fa`（v3.1.6：修竖排水印的断句）；2026-10-06 实测记录。
