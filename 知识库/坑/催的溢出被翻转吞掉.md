# 催的溢出被翻转吞掉

**结论**：`_advancePhase` 翻转相位时原来把 `elapsedInPhase` 直接清零 —— 「催」在本相位只剩 1 格时使用，第二格时间凭空消失：下一次翻转晚 1 手，一个完整周期从 2P 手变成 2P + 1 手。2026-10-25 审计 BUG-01（P2），已修。

**复现**：`phasePeriod = 10`，先正常落 9 手（`elapsed = 9, target = 10`），第 10 手用「催」。

- 修前：`phase = 1, elapsed = 0, target = 11, debt = 0` —— 越过旧目标的 1 格被清零。
- 修后：`phase = 1, elapsed = 1, target = 11, debt = 0`，`handsUntilFlip = 10`。

**为什么**：RULES_SPEC §10.5 说的是「催：时间走两格」「一个完整周期总长恒为 2 × 周期，借来的从下一个相位扣」。催的第二格如果正好越过翻转点，它落在**新相位**里；清掉它等于把时间扔掉 —— 玩家用「加速」，反而换来更慢的翻转。

**修法与边界**：翻转前记下 `overflow = elapsedInPhase − phaseTarget`，结算完债（`phaseTarget = P − phaseDebt`，用清零前的债）后把 `elapsedInPhase = overflow`。
溢出最多 1 格（只有「催」一次加 2 格）；新相位至少 `MIN_PHASE_HANDS = 2` 格，而催触发翻转时目标实际 ≥ 3，所以不会一次翻两个相位，不需要循环。

**证据**：`Web_Gomoku3D/tests/rules.test.mjs` 第 5 节 —— 5.1 翻转瞬间 `elapsed = 1 / target = 11`；5.2 完整周期仍是 20 手；5.3 悔棋退回翻转前的时钟快照。`_verify/phase-probe.mjs` 全绿。

**出处**：2026-10-25 游戏 Bug 审查 BUG-01（P2；按约定，修复完成后的审查记录已删除）；[[RULES_SPEC]] §10.5。
