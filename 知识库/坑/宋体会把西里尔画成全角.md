# 宋体会把西里尔画成全角

**症状**：俄语标题文字异常宽——「Тринадцать направлений…」自然宽实测 **856px**（65 个字符平均 13.2px，几乎一个汉字宽）。看上去像"俄语太长 / 文案问题"，实际是字体回退。

**原因**：标题块挂着 `class="serif"`，而 `.serif` 写死楷体栈（KaiTi / STKaiti / …）；**楷体没有西里尔字形** → 回退到 **SimSun（宋体）** → 宋体把西里尔字母按**全角**宽度渲染。

**规矩**：加 `.serif` 这类"装饰类"时，**必须同时给它一份按语言的字体栈**——页面本来有 `html.lang-en/fr/ru body` 的规则，但类选择器会把它整个覆盖掉。排查自然宽的快捷法：把元素临时设成 `white-space: nowrap; width: max-content; max-width: none`，量出来和同长度的拉丁文本比一比就知道有没有掉进全角回退。换字体之后 `max-width` 的门槛会整体位移，两个数要一起重算。

**出处**：`6373885`（v3.1.6：修西里尔字母被画成全角）；2026-10-06 实测记录（换 Georgia 后 856px → 485px）。
