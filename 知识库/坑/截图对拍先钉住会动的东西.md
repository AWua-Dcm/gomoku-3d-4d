# 截图对拍先钉住会动的东西

**症状**：对拍出 25.6% / 16.7% 的"差异"，据此断定"改动污染了画面"——**同一个坑连踩两次，两次都是错的结论**，还基于错的结论动了一次手。

**原因**：图里本来就有会自己动的东西——对局截图里那条 toast 会自行淡出、起始界面演示盘的 yaw 每秒转 6°。相隔几百毫秒的两张图，量到的是时间差，不是改动。

**规矩**：①对拍前先**连拍两张同状态图量噪声底**——底不是 0，后面的差异数字全部作废；②时间相关的量先钉死（`Game.showToast = ()=>{}` + 去 transition + `toastTimer = 1e9`；起始界面 `previewYaw = -28`）；③别"把证人赶走"——为了消掉淡出干脆 `display:none` toast，正好把唯一能照出污染的浮层藏了，A/B 都是零差异，**假绿**；④差异分级：色差 > 150 的**聚块（强差异）一定追**，文字抗锯齿（弱差异）别追（v3.1.5 就是靠这条抓到「退出」印成「设置」，强差异 176 像素正好一个按钮）。

**出处**：2026-09-28 两次翻车 + 2026-10-01（v3.1.5）实测；判据与数字都在当时的会话记录里。
