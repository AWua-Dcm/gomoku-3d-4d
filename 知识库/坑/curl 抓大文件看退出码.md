# curl 抓大文件看退出码

**症状**：抓线上的 `index.html`（257KB）md5 对不上、甚至 0 字节，一度怀疑"Pages 发的内容和本地不一致"——方向完全错了。

**原因**：走本地代理 + `curl --max-time` 给得太短时，curl **超时退出但把半截内容落了盘**，`-o` 出来的文件看着像正常响应。

**规矩**：识别它的三个特征要一起看——响应头 `Content-Length` 是完整的（如 257510），但落盘 `wc -c` 只有零头；截断点常切在多字节字符中间（`head -c` 会看到 �）；**同一个 URL 重抓就正常**（真有问题的话是稳定复现的，不是随机的）。对策：抓大文件 `--max-time` 给到 180，**一定要显式看 curl 退出码**（`-w '%{http_code}'` 只看 HTTP 状态，超时照样返回 200）：

```bash
curl -s --max-time 180 -w '%{http_code}' -o out.bin "$URL"; echo "rc=$?"
```

`rc=0` 才算抓全。md5 对不上先重抓三次，稳定复现才当回事。

**出处**：2026-09-26 验收 GitHub Pages 时实测（连续抓 8 次有 1 次对不上、几次 0 字节）。
