# 冻结向量不能改

**症状**：想让测试变绿、想"重新生成"向量——做不到，而且这个念头本身就是方向错了。

**原因**：这两份 json（`tests/vectors.json`、`tests/rotation-vectors.json`）来自一份**早已删除**的 C# 内核——当年导出它们的脚本连同那份源码一起消失了。所以：**永远无法重新生成**。锁定它们的是 `run-all.sh` 的第 2 步（md5 校验）。

**规矩**：为了让测试变绿而改动它们**不是修 bug，是篡改证据**。它们的含义是"和 2026-09 那份 C# 实现逐手一致"，是一份**冻结的历史基线**，不是和某个活对照物的对拍。
