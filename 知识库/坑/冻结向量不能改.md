# 冻结向量不能改

**症状**：想让测试变绿、想"重新生成"向量——做不到，而且这个念头本身就是方向错了。

**原因**：`Web_Gomoku3D/tests/vectors.json` 与 `rotation-vectors.json` 是从一份**已经删除**的 C# 内核导出的；导出脚本和 C# 源码本身都已不存在。这意味着：**这两个文件永远无法重新生成**。`run-all.sh` 第 2 步用 md5 把它们钉死。

**规矩**：为了让测试变绿而改动它们**不是修 bug，是篡改证据**。它们的含义是"和 2026-09 那份 C# 实现逐手一致"，是一份**冻结的历史基线**，不是和某个活对照物的对拍。
