# 视觉重构 v3.1.6

**结论**：2026-10-06 起始界面全面古风化——改名「五子魔方 / Gomokube」（六语言）、宣纸底 + 竹简 / 玉牌器物、行书主标题、竖排古文水印、背景字符粒子层。

**做了什么**（细节在当时的连续提交里）：

- **行书主标题**：内联字体子集 5.5KB 守住单文件（`7c842c1`；后来重切见 [[决策/单文件里塞书法字体]]）。
- **竖排古文水印**：「亦有格五，其法布子成行，以得五者胜」——出过一次断句坑，`3ab96fa` 修掉（见 [[坑/fixed 只写 top50 会截高度]]）。
- **字符粒子层**（`e7b2002`）：鼠标划过时字被推开、移开弹性归位，右密左疏；全静止时连 rAF 都停。收敛后的亚像素爬行闪烁后来单独修过（`84d8e09`）。
- **放大与布局连调**：主标题两次放大（`8c66a1b`、`b7fccc2`），水印搬进"棋盘与设置区之间"的空位；西里尔全角回退与两行小字折行同期修复（`6373885`）。

**更早的一版背景（v2.10.13）**：用户要"古风 + 一点点赛博"，**先出三版样图让他挑**，他选了最保守的 F3——不加任何图案，只把光重打一遍（两层晕染改三层、方向一致）+ 印章加两圈朱砂外发光（`6299ed2`）。那一版的调研结论沉淀成了 [[决策/古风视觉的规矩]]。

**这段历史的两条经验**：①出样图再动手（三选一比边做边改省得多）；②改背景走 `--paper-img` 变量而不是重写 `.paper`——`.paper` 和演示盘共用同一份，两边各写一份会在 42% 那条线上裂出缝。
