# 版本脉络

**结论**：一句话一条看懂主线——逐条的细节在 [[README]] 的更新日志里，这里只补每段的"为什么转"。

- **v1.0.0（09-23）** 三维五子棋雏形：立体棋盘、13 方向、长连负。
- **v2.0.0（09-24）** 四维模式：棋盘能像魔方一样转层——**玩法后续更新**（转层真正接进对局是 v2.10 前后的事）。
- **v2.4 – v2.7（09-24/25）** 中英双语 → 竖屏 / 触屏支持：界面开始按"多种语言 × 多种屏幕"设计，六语言的排版坑（西里尔全角、法语高度）都是这一线的延伸。
- **v2.10 系列（09-27 – 09-29）** 电脑对手从三档到五档、评估函数重写、转动从"抢跑"改"按威胁触发"再到"两步确认"。这是 AI 与交互密度最高的一线，详细战史见 [[历史/AI 棋力提升史]]。
- **v3.0.0（09-29）** 三机制一起上：贯通（环面）、晨昏（相位 / 催 / 缓）、游戏教学三关——三条机制互相独立但共用底层，所以一次做完（见 [[决策/贯通看得见]]）。
- **v3.1.x（09-30 – 10-09）** 视觉重构（"五子魔方"，v3.1.6，见 [[历史/视觉重构 v3.1.6]]）+ 逐版清账（v3.1.4 补验证、v3.1.5 / v3.1.7 修批量的界面状态与内核判定问题）。
- **v3.1.8（10-14）** 玩法审计清账：一轮独立排查找到并修掉三处玩法缺陷（四维"夜间搜索瞎掉"、先手转动自尽、结算看扫描顺序），并让规则正文照实现——晨昏从此不做"定时炸弹"承诺（见 [[决策/晨昏不做定时炸弹]]、[[坑/模拟落子漏了相位]]）；同版追加「对局记录」（见 [[决策/对局记录只存摘要]]）。
- **v3.1.10（10-21）** 新增网页图标；右上角加入打赏入口（二维码 + 爱发电），打赏不影响功能。
- **v3.1.9（10-21）** 公开版收口：仓库只保留单机功能，公开分发只含单机网页；测试收成八步、32091 项。
- **还没走完的**：AI 棋力（70% 验收线，见 [[待办/AI 棋力欠账]]）、拓扑玩法的两档（见 [[待办/拓扑玩法的两档]]）。

**纪律一条**：版本号不许跳线——原挂 v2.11.0 的改动后来改成 v2.10.13（"2.10 这条线没走完，不该跳到 2.11"），旧 commit message 不改写（见 [[历史/被否掉与被撤掉的东西]]）。
