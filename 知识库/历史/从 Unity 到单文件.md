# 从 Unity 到单文件

**结论**：这个工程**原来是个 Unity 工程**，C# 实现已经整体删除，现在只有网页版。文档里凡提"C# 内核""C# 导出的向量"的地方，指的都是那段**已经不存在**的历史。

**为什么要记这件事**：因为理解了它，才能正确读三样东西——

- [[打开流程]] 文件头那句"这是历史沿革，不是当前状态"：那份文档保留着 Unity 时代的痕迹，是沿革记录；
- 两份**冻结向量**的来源：`vectors.json` / `rotation-vectors.json` 就是从那份已删除的 C# 导出、因此**永远无法重新生成**（见 [[坑/冻结向量不能改]]）；
- [[Web_Gomoku3D/README|工程细节 README]] 里「与已删除的 Unity 版的结构对应（历史）」一节：记着旧工程的哪些模块迁到了网页版的哪里，含三处刻意的差异。

**网页版与旧版的关系**：网页版是重写而不是移植——但规则内核被单独夹在 `/* GOMOKU-CORE-BEGIN/END */` 里、不碰浏览器 API，就是为了一件事：让"只有一份实现"（见 [[决策/单文件零依赖]]）在换引擎时也守得住。

**出处**：[[打开流程]] 文件头；[[Web_Gomoku3D/README|工程细节 README]]「与已删除的 Unity 版的结构对应（历史）」节。
