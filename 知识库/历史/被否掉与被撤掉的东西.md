# 被否掉与被撤掉的东西

**结论**：这里收"曾经存在过、被撤或被否"的东西——理解它们比理解现役功能更省事：不用再重新提议一遍。

- **「恢复本次转动」按钮被撤（v2.10.11）**：位置让给常驻的「确定操作 / 取消操作」。**撤之前专门核过能力没丢**——键盘 `Y` 走 restoreRotation()，鼠标 / 触屏走「悔棋 Z」（最后一步是转动时撤的就是它）。
- **`display:none` 换位被否**：v2.10.10 用隐藏 / 显示来换那行按键，用户否掉；v2.10.11 改成两个键**常驻灰显**（`:disabled`）。
- **试过、量过、没留下的算法**：算杀进叶子（50.0%、耗时翻倍）；低档三条变强路（46.7 / 40.8 / 47.5%）；支 6；深 6（577ms 且只强 60%）。数字都在代码注释和提交说明里——**别再试一遍**。
- **版本号改号**：原挂 v2.11.0 的起始界面改动改号成 v2.10.13（`163d5ed`，理由：2.10 这条线没走完、不该跳到 2.11）。历史提交 `6299ed2` / `4a52f60` 的 message 里仍写着 v2.11.0——**没有改写历史**，这是刻意的。
- **格线 blendFunc 的"修了又恢复"**：2026-09-27 查清根因（`blendFunc` 让 alpha 自身平方）并改好、验证全绿，但中途用户说"不用改了，恢复"，全部撤销。后来为了另一个需求重新量帧缓冲，发现**对局态也中招**（浅色格线会被合成器冲成纯白），最终 v2.10.12 用 `colorMask` 方案按 `setupOpen` 分开修——起始界面一个像素没动，正好也守住了"不改起始界面"那个决定。

**出处**：`4b973f6`、`d571ff0`、`163d5ed`、`6299ed2`、`36eddb3`、v2.10.12 提交记录。
